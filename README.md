# TeddyBearBar — сайт детского кафе

Многостраничный статический сайт для кофейни и детского кафе TeddyBearBar (Минск, просп. Дзержинского, 92). Чистые HTML, CSS и JavaScript, без сборки.

## Особенности
- **Переключатель тёмной и светлой темы** (кнопка в шапке). Выбор запоминается, по умолчанию берётся тема системы.
- Анимированные счётчики и полосы отзывов, бегущая строка, полоска прокрутки, плавное появление блоков (отключается при «уменьшить движение»).
- Меню с фильтром по категориям.
- Заявка на праздник открывает WhatsApp с готовым сообщением.
- На телефоне внизу панель «Позвонить» и WhatsApp.

## Страницы
`index.html`, `menu.html`, `party.html` (праздники и заявка), `faq.html`, `contacts.html`.

## Запуск
`python3 -m http.server 8000` и открыть http://localhost:8000

## GitHub Pages
Загрузите содержимое папки в корень репозитория, затем Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Что править
- **Меню и цены** — `menu.html` (взято с фото меню; сезонное меняется).
- **Телефоны** — футер каждой страницы, `contacts.html`, `main.js` (форма праздника).
- **Время работы и цены на праздники** — на сайте не указаны.
- **Цвета обеих тем** — переменные в начале `style.css` (`:root` и `[data-theme=dark]`).
- Шрифты: Comfortaa и Nunito (Google Fonts).

Данные взяты с карточки на Яндекс Картах и из фото меню.
